## Dictation

Press the default hotkey, `Ctrl+Alt+Space`, speak, and the text appears where the cursor is.

The recognition language is set in the settings. It stays fixed until you change it.

## Insertion and the clipboard

Insertion does not depend on the keyboard layout: `Shift+Insert` inserts the recognized text, and the clipboard is restored after the insertion.

## Settings

Settings are grouped in tabs:

- Recording
- Model & language
- Dictionary
- History
- Appearance
- System

The recognition model can be changed.

## Dictionary

The dictionary can be imported and exported, with a preview before applying changes.

## History

History is disabled by default. When enabled, it keeps the last 100 dictations in `history.jsonl`.

## Interface

The interface is available in English and Russian. VibeForma has a monitoring panel, a tray icon and autostart.
