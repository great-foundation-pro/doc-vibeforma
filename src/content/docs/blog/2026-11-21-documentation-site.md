The VibeForma documentation now has its own site. The first version describes the product from several sides and keeps a public record of how the site itself is built.

## What is on the site

- [Introduction](/introduction/) — what VibeForma is and what comes with it.
- [Installation](/installation/) — requirements, the quick install command and installer parameters.
- [Usage](/usage/) — the input hotkey, insertion, settings, dictionary and history.
- [Privacy](/privacy/) — local recognition, the network, history.
- [Troubleshooting](/troubleshooting/) — what to check when something does not work.

Every page exists in English and Russian, and the language switch in the header keeps the current section.

## Blog and journal

The blog carries notes about the product and the project. The [logs](/logs/) section is the development journal of the site itself — not the log files of the application.

## What comes next

The documentation is written from verified facts about the product. Pages will be extended as the project confirms new details. The source code of VibeForma is in the [FormaMindPro/vibeforma](https://github.com/FormaMindPro/vibeforma) repository under the MIT license.
