Эта страница — честная граница продукта. Часть пределов — намеренный выбор, часть — известные проблемы, часть — вне границ.

## Платформа

| Ограничение | Деталь |
|---|---|
| Только Windows | Windows 10 сборки 1809+ или Windows 11, x64 или ARM64. Версий для macOS, Linux, iOS и Android нет. |
| Один экземпляр | Одновременно работает один сервис (`service.lock`). Повторный запуск просит работающий экземпляр показать панель. |
| Профили GPU | VibeForma поставляет профиль NVIDIA CUDA и профиль CPU. Другие производители GPU не являются документированным профилем. |

## Распознавание

| Ограничение | Деталь |
|---|---|
| Нет автоопределения языка | Язык фиксируется в настройках и действует, пока вы его не смените. |
| Один язык на фразу | Переключения внутри фразы и перевода нет. |
| 26 кодов в меню | Меню предлагает 26 кодов языков; модель поддерживает около 99 языков. Меню — не полный список модели. |
| Нет разделения говорящих | VibeForma не разделяет говорящих. |
| Лимит фразы 120 секунд | Более длинная запись останавливается на пределе. |
| Нет транскрибации файлов в 0.2.4 | Аудио- и видеофайлы заявлены для 0.3.0, сегодня недоступны. |

## Установка и обновления

| Ограничение | Деталь |
|---|---|
| Неподписанная сборка | Сертификата подписи кода и подписанного манифеста нет. Windows SmartScreen может предупредить. |
| Контрольные суммы, не подписи | Релизы выходят с `SHA256SUMS`; сумма ловит повреждение, но не авторство. |
| Нет молчаливого обновления по умолчанию | Релиз предлагается; автоматическая установка только при `auto_update: auto`. |
| Нужен Python | Установщику нужен Python 3.10–3.14 на машине. |

## Документация

| Проблема | Деталь |
|---|---|
| Устаревшее упоминание `VibeForma.exe` | README продукта всё ещё называет `VibeForma.exe` в разделе командной строки. Отдельного исполняемого файла в 0.2.4 нет: используйте `run.cmd` или `.venv\Scripts\python.exe main.py`. |
| Будущие страницы зарезервированы | Страницы транскрибации файлов, форматов и агентов зарезервированы, но не публикуются до выхода функции. |

## Данные и история

| Ограничение | Деталь |
|---|---|
| Предел истории | Последние 100 диктовок. |
| Нет экспорта истории | У таблицы нет действия экспорта. |
| Предел словаря и сниппетов | До 500 пар каждого. |
| Менеджеры буфера | Сторонний менеджер буфера может сохранить продиктованный текст, хотя история и облачная синхронизация Windows исключены. |
| Окно отмены | `Ctrl+Z` работает только в течение 30 секунд и в том же окне. |

## Локальный API

| Ограничение | Деталь |
|---|---|
| Выключен по умолчанию | API не слушает, пока вы его не включите. |
| Только loopback | Удалённого доступа нет. |
| WAV до 10 МБ | Одна короткая запись на запрос. |
| Один запрос в секунду | Более частый клиент получает `429`. |
| Только простой | У диктовки приоритет; занятый сервис возвращает `409`. |

## Вне границ

Это не планируется как часть продукта диктовки:

- разделение говорящих;
- перевод;
- субтитры для видео;
- облачное распознавание;
- пакетная обработка очередей файлов;
- встречи, конспекты, команды и биллинг;
- мобильные приложения.

## Известные проблемы окружения

- **Bluetooth-гарнитуры** могут переключаться в низкокачественный hands-free профиль. Если качество распознавания упало, используйте проводной или USB-микрофон.
- **Конфликты горячих клавиш** с другим приложением не дают зарегистрировать сочетание. Выберите другое в настройках.
- **Антивирус** может отметить неподписанный установщик. Сверьте контрольную сумму и разрешайте файл, только если доверяете источнику.
- **Очень слабые CPU** делают крупные модели медленными. Используйте `small` или `large-v3-turbo`, либо машину с CUDA.
- **Место на диске** должно вмещать модель плюс рабочий запас; обновлению нужно место под архив и бэкап.
