VibeForma — локальное настольное приложение. У неё нет облачного сервиса, системы аккаунтов и удалённого бэкенда. Поэтому модель безопасности небольшая и явная: защитить локальную машину, держать API на loopback, проверять загружаемое и не исполнять недоверенный ввод.

## Модель угроз

| Актив | Кто может добраться | Защита |
|---|---|---|
| Продиктованный текст | Локальный процесс, менеджер буфера, целевое приложение | Локальная обработка; исключение из буфера; без выгрузки |
| История и статистика | Локальный пользователь с вашей учётной записью Windows | Права файлов Windows; история выключена по умолчанию |
| Токен API | Локальный процесс, читающий `config.json` | Права учётной записи Windows; слушатель только на loopback |
| Архив обновления | Сеть | `SHA256SUMS`; бэкап и откат |
| Команда хука | Сама настроенная команда | Без shell; таймаут; параллельное выполнение |

VibeForma не защищает от скомпрометированной учётной записи Windows. Если атакующий читает ваш профиль, он прочитает и `config.json`.

## Локальный API

| Контроль | Деталь |
|---|---|
| Адрес привязки | Только `127.0.0.1` |
| Токен | `X-VibeForma-Token` в каждом запросе |
| Сравнение | Постоянного времени (`hmac.compare_digest`) |
| Лимит тела | 10 МБ |
| Тип содержимого | Только `audio/wav` |
| Ограничение частоты | Один запрос в секунду |
| Занятый сервис | `409`; у живой диктовки приоритет |
| Временное аудио | Удаляется при любом исходе |
| TLS | Не используется; трафик не покидает loopback |

API выключен по умолчанию. Если токена нет, слушатель не стартует — fail-closed.

## Команда хука

`hook_command` запускает пользовательскую команду с распознанным текстом на stdin:

- shell не участвует, поэтому `|`, `>`, `&&` и раскрытие переменных — обычные символы;
- таймаут 1–30 секунд;
- сбой или таймаут пишется в лог как статус и не блокирует вставку;
- хук работает параллельно со вставкой.

Хук — намеренная поверхность исполнения кода: то, что вы настроили, выполнится с вашими правами. Относитесь к `hook_command` как к записи в профиле оболочки.

## Обновления

| Контроль | Деталь |
|---|---|
| Источник | GitHub Releases |
| Целостность | `SHA256SUMS` |
| Подпись | Нет — ни сертификата подписи кода, ни подписанного манифеста |
| Бэкап | Сохраняется перед установкой |
| Откат | Восстанавливает бэкап при сбое |
| SmartScreen | Может предупредить, потому что сборка не подписана |

Контрольная сумма ловит повреждённую загрузку; она не доказывает, кто собрал архив. Скачивайте только из официального репозитория и сверяйте сумму.

## Буфер обмена

- Прежний буфер возвращается примерно через секунду, если ничего нового не скопировали.
- Продиктованный текст помечается исключённым из истории буфера Windows и облачного буфера.
- Сторонний менеджер буфера всё равно может его перехватить; это вне контроля VibeForma.

## Файлы

- `config.json` содержит токен API открытым текстом. Защищайте его правами учётной записи Windows.
- `location.json` секрета не содержит.
- Логи никогда не содержат продиктованный текст; заголовки окон включаются отдельно.
- История выключена по умолчанию; её выключение удаляет файл.

## Один экземпляр

`service.lock` не даёт второму сервису стартовать. Два сервиса конкурировали бы за микрофон, горячую клавишу и порт API и давали бы путаное поведение.

## Что намеренно не является границей безопасности

- Словарь и сниппеты — не защищённое хранилище.
- История не шифруется.
- Режим приватности панели скрывает текст с экрана, но не от процесса.
- Токен API не заменяет безопасность учётной записи ОС.

## Сообщение об уязвимости

Откройте приватный security advisory в репозитории [FormaMindPro/vibeforma](https://github.com/FormaMindPro/vibeforma). Если advisory недоступны, свяжитесь с сопровождающими через репозиторий, не выкладывая детали эксплойта в публичный issue.

Укажите:

- версию;
- затронутый компонент — API, хук, установщик, обновлятор, буфер;
- шаги воспроизведения;
- наблюдаемое воздействие.

Не прикладывайте токен API, продиктованный текст или личные файлы.
