VibeForma ставится скриптом PowerShell в профиль пользователя. Права администратора не нужны, а системные каталоги установщик отклоняет намеренно.

Требования — в разделе [Системные требования](/ru/requirements/). Самый короткий путь — [Быстрый старт](/ru/quickstart/).

## Установка одной командой

Откройте PowerShell и выполните:

```powershell
irm https://raw.githubusercontent.com/FormaMindPro/vibeforma/main/install.ps1 | iex
```

Скрипт находит Python, скачивает последнюю выпущенную сборку, ставит её, скачивает модель и запускает сервис.

Ставятся только выпущенные сборки. Если релизного архива нет, бутстрап останавливается с причиной, а не подменяет релиз веткой `main`.

## Параметры установщика

| Параметр | Значения | Что делает |
|---|---|---|
| `-Model` | `large-v3`, `large-v3-turbo`, `medium`, `small` | Выбирает модель распознавания вместо вопроса. |
| `-Target` | путь к каталогу | Ставит в этот каталог вместо `%LOCALAPPDATA%\VibeForma`. |
| `-Cpu` | флаг | Принудительно включает профиль CPU (int8) вместо попытки CUDA. |
| `-DryRun` | флаг | Выполняет проверки и печатает план, ничего не меняя. |
| `-NoRun` | флаг | Ставит приложение, не запуская сервис. |

Чтобы передать параметры, сначала сохраните скрипт:

```powershell
irm https://raw.githubusercontent.com/FormaMindPro/vibeforma/main/install.ps1 -OutFile install.ps1
.\install.ps1 -Model small -Target D:\VibeForma -NoRun
```

## Что проверяет установщик

До первой записи установщик проверяет:

- Windows 10 сборки 1809 или новее.
- Архитектуру x64 или ARM64.
- Python 3.10–3.14.
- Свободное место под модель плюс около 4 ГБ.
- Целевой каталог: пустой, существующая установка VibeForma или папка с маркером установки.
- Что цель не является системным каталогом, `Program Files`, корнем диска или корнем профиля пользователя.

Первый сбойный шаг останавливает цепочку. Каждый шаг и хвост ошибки пишутся в `install.log`.

## Установка как транзакция

Установка — не набор несвязанных записей:

- Предпроверки выполняются до первого изменения.
- При провале первой установки созданная папка удаляется.
- При провале обновления существующая установка восстанавливается из бэкапа.
- Повторный запуск продолжает с места сбоя, переиспользуя виртуальное окружение, модель и конфигурацию, если они целы.

## Выбор модели

Установщик показывает диалог с четырьмя моделями, их размерами и описаниями. При необслуживаемом запуске выбирается `large-v3-turbo`; на машине только с CPU — `small`. На существующей установке сохраняется модель из `config.json`.

Компромиссы описаны в разделе [Модели и языки](/ru/models/).

## Каталог установки

По умолчанию — `%LOCALAPPDATA%\VibeForma`. Чтобы поставить в другое место, используйте `-Target`, например `D:\VibeForma`.

Защищённые каталоги установщик отклоняет: приложение, которое пишет конфигурацию и модели рядом с собой, не должно жить там, где Windows ожидает системные файлы.

## Ярлыки и точка входа

Установщик создаёт ярлыки на рабочем столе, в меню «Пуск» и в автозапуске. Они запускают приложение напрямую через `pythonw.exe main.py`, а не через `run.cmd`, поэтому консольное окно не появляется.

Приложение также регистрируется в **Параметры → Приложения** без прав администратора. Версия показывается в настройках.

## Первый запуск

После установки сервис запускается и появляется помощник из трёх шагов:

1. Язык интерфейса и распознавания.
2. Микрофон с живым уровнем и пробной записью.
3. Горячая клавиша диктовки, записываемая нажатием.

**Пропустить** записывает безопасные значения по умолчанию. Помощник можно снова открыть из трея и из настроек. Флаг `onboarding_done` в `config.json` отмечает, что помощник пройден.

## Обновление

Обновления используют тот же релизный архив и тот же установщик. Автоматические проверки описаны в разделе [Обновления](/ru/updates/). Модель, словарь, история и `config.json` сохраняются.

## Удаление

Выполните:

```powershell
uninstall.cmd
```

или:

```powershell
python uninstall.py
```

Удалятор убирает ярлыки, запись автозапуска, запись в **Приложениях** и файлы сервиса. Модели и `config.json` по умолчанию остаются, поэтому переустановка стартует офлайн.

| Флаг | Действие |
|---|---|
| `--remove-data` | Удаляет также модели и `config.json`. |
| `--keep-data` | Сохраняет данные без вопроса. |

## Если установка не удалась

1. Прочитайте `install.log` в каталоге установки — там назван сбойный шаг и хвост ошибки.
2. Запустите `install.ps1 -DryRun`, чтобы увидеть проверки без изменений.
3. Проверьте версию Python: 3.10–3.14.
4. Проверьте свободное место: размер модели плюс около 4 ГБ.
5. Повторите ту же команду. Повторный запуск продолжает с места сбоя.
