VibeForma локальна по устройству: распознавание речи идёт на вашей машине, аккаунта, облака и телеметрии нет.

## Что никогда не покидает машину

- **Аудио.** Оно захватывается и распознаётся на этой машине и никогда не выгружается. Когда вы решаете его сохранить — включённый звук истории или запись системного звука, — запись остаётся в локальном файле.
- **Аудио файлов и расшифровки.** Файлы декодируются и распознаются локально. Расшифровка пишется рядом с исходником только когда вы транскрибируете файл, и не выгружается.
- **Распознанный текст.** Он уходит в целевое окно и, если вы включили историю, в локальный файл. Он не выгружается.
- **Словарь, сниппеты, hotwords.** Они остаются в `config.json`.
- **История и статистика.** Оба файла локальные.
- **Логи.** Они лежат в `logs\` и никогда не содержат продиктованный текст.

## Когда используется сеть

Сеть используется ровно для двух целей:

| Цель | К чему обращается | Когда |
|---|---|---|
| Загрузка модели | Источник распространения модели; общий кэш Hugging Face используется, если модель там есть | При установке или при переключении на модель, которой нет на диске |
| Проверка и загрузка обновлений | GitHub Releases | Примерно через 90 секунд после старта, далее каждые `update_interval_h` (2 часа) в простое, либо по кнопке **Проверить сейчас** |

Само распознавание сетевых запросов не делает. С выключенными проверками обновлений приложение само к GitHub не обращается.

Нет ни сервиса аналитики, ни эндпоинта отчётов о падениях, ни сервера аккаунтов, ни проверки лицензии.

## Что пишется на диск

| Файл | Содержит | По умолчанию |
|---|---|---|
| `config.json` | Настройки, словарь, сниппеты, hotwords, модель, язык, токен API | Всегда |
| `models\` | Модель распознавания | Всегда |
| `logs\` | Смены состояний, вставки с числом знаков, ошибки | Всегда; без продиктованного текста |
| `history.jsonl` | Последние 100 диктовок с текстом | Выкл. |
| `history_audio\` | Один 16-битный WAV на диктовку, рядом с `history.jsonl`; папка ограничена 200 МиБ, первым уходит самый старый файл | Выкл.; только при включённой истории |
| `stats.json` | Четыре счётчика за день | Всегда, только числа |
| `corrections.json` | Только слова, изменённые обучением из правок | Когда обучение используется |
| `location.json` | Пути и фактический порт API; без секрета | Пока сервис работает |
| `status.json` | Состояние, версия, pid, метка времени | Пока сервис работает |
| `service.lock` | Блокировка одного экземпляра | Пока работает |

## История включается отдельно

История выключена по умолчанию. Когда вы её включаете, она хранит последние 100 диктовок в `history.jsonl` рядом с `config.json`. Выключение **удаляет файл** и сохранённый звук.

История хранит текст, имя приложения и направление, а заголовки окон — никогда. При включённом `history_audio` она хранит ещё и WAV каждой диктовки в папке `history_audio\` рядом с `history.jsonl`, а эта папка ограничена 200 МиБ, и первым уходит самый старый файл. Удаление записи удаляет её WAV, очистка истории удаляет сохранённый звук, а выключение `history_audio` убирает звук, сохранённый прошлым запуском.

## Статистика — только числа

`stats.json` хранит диктовки, слова, знаки и секунды по дням. Он никогда не хранит текст, слова строками, имена приложений или заголовки окон.

## Буфер обмена

- Прежний буфер возвращается примерно через секунду после вставки, если ничего нового не скопировали.
- Продиктованный текст помечается исключённым из истории буфера Windows и облачного буфера (`CanIncludeInClipboardHistory=0`, `CanUploadToCloudClipboard=0`).
- Сторонний менеджер буфера всё равно может сохранить текст; настройки об этом предупреждают.

## Режим приватности панели

Кнопка-глаз скрывает стриминг и последний текст; уровень микрофона остаётся видимым. `hud_privacy: true` запускает панель в этом режиме. Строка статуса исчезает через 30 секунд.

## Логи

- Продиктованный текст в лог не пишется никогда.
- Заголовки окон пишутся только при `log_window_titles: true`. По умолчанию в логе хэндл окна и число знаков.
- Логи ротируются: пять файлов по 1 МБ.

## Локальный API

API выключен по умолчанию. Когда он включён, он слушает только `127.0.0.1`, требует токен в каждом запросе, принимает WAV до 10 МБ не чаще раза в секунду и удаляет временный WAV при любом исходе.

## Диагностика

Отчёт `--doctor` только читает и исключает продиктованный текст, заголовки окон, hotwords, словарь, историю и HTTP-токен. Вывод `--selftest` — распознанная тестовая фраза из `test_ru.wav`.

## Удаление данных

| Что удалить | Что сделать |
|---|---|
| История и её звук | Выключить историю (удаляет `history.jsonl` и сохранённый звук), удалить запись (удаляет её WAV) или выключить `history_audio` (убирает сохранённый звук при следующем старте) |
| Статистика | Сбросить на вкладке «Статистика» или удалить `stats.json` |
| Данные обучения | Удалить `corrections.json` |
| Модели и настройки | Удалить приложение с `--remove-data` или удалить каталог установки |
| Всё | Удалить с `--remove-data` и стереть оставшуюся папку |

## От чего VibeForma не защищает

- Локальный пользователь с доступом к вашей учётной записи Windows может прочитать `config.json`, историю и статистику.
- Установленный вами менеджер буфера может перехватить продиктованный текст.
- Запись экрана может захватить панель, когда режим приватности выключен.
- Токен локального API хранится в `config.json` открытым текстом; защищайте файл правами учётной записи Windows.
