---

Термины приведены в английской и русской форме, как в приложении и на этих страницах. Где интерфейс использует английскую подпись в обеих локалях, это отмечено.

| Термин | По-русски | Значение |
|---|---|---|
| ASR | Распознавание речи | Автоматическое распознавание речи — превращение аудио в текст. |
| Whisper | Whisper | Семейство открытых моделей распознавания, на котором строится VibeForma. |
| faster-whisper | faster-whisper | Локальная реализация Whisper, которую использует VibeForma. |
| Model | Модель | Файл модели распознавания: `large-v3`, `large-v3-turbo`, `medium`, `small`. |
| VAD | VAD (определение речи) | Определение голосовой активности — решает, есть ли речь в кадре. |
| Hotkey | Горячая клавиша | Глобальное сочетание, которое начинает и останавливает диктовку. |
| Toggle mode | Режим toggle | Нажали — старт, нажали ещё раз — стоп. |
| Hold to talk | Режим удержания | Держите клавишу, пока говорите, отпускаете — стоп. |
| Panel / HUD | Панель | Небольшое окно мониторинга с уровнем, VAD и потоком текста. |
| Tray | Трей | Значок в области уведомлений Windows и его меню. |
| Insertion | Вставка | Помещение распознанного текста в позицию курсора целевого окна. |
| Paste method | Метод вставки | `Shift+Insert` (по умолчанию) или `Ctrl+V`. |
| Clipboard restore | Возврат буфера | Возврат прежнего буфера примерно через секунду после вставки. |
| Dictionary | Словарь | Пары термин → замена, до 500. |
| Hotwords | Личные термины | Термины, всегда входящие в подсказку распознавания. |
| Snippet | Сниппет | Произносимый триггер, заменяемый подготовленным текстовым блоком. |
| History | История | Необязательная локальная запись последних 100 диктовок. |
| Statistics | Статистика | Локальные счётчики диктовок, слов, знаков и секунд. |
| Hook | Хук, `hook_command` | Пользовательская команда, получающая распознанный текст на stdin. |
| File transcription | Транскрибация файлов | Распознавание аудио- или видеофайла вместо микрофона. |
| Folder batch | Пакет папки | Очередь медиафайлов одной папки, обрабатываемых по одному. |
| Job | Задача | Один файл в очереди; состояние и прогресс видны через `/jobs`. |
| Transcript | Расшифровка | Текстовый результат в TXT, JSON, SRT или VTT. |
| SRT / VTT | SRT / VTT | Форматы субтитров с таймкодами. |
| Named pipe | Именованный канал | Локальный канал на пользователя, который CLI использует без порта и токена. |
| Local API | Локальный API | Необязательный HTTP-слушатель на `127.0.0.1`. |
| Loopback | Loopback | Локальный интерфейс `127.0.0.1`; трафик не покидает машину. |
| Token | Токен | Секрет, требуемый локальным API; хранится в `config.json`. |
| `location.json` | `location.json` | Файл обнаружения с фактическим портом API; секрета внутри нет. |
| `status.json` | `status.json` | Файл состояния сервиса: state, version, pid, ts. |
| Onboarding | Онбординг, помощник настройки | Помощник первого запуска из трёх шагов. |
| SHA256SUMS | `SHA256SUMS` | Файл контрольных сумм для проверки релизного архива. |
| Endonym | Эндоним | Название языка на самом языке, например Русский. |
| FormaMind | FormaMind | Проектный инструмент, голосовым слоем которого является VibeForma. |
| MIT | MIT | Открытая лицензия VibeForma. |
