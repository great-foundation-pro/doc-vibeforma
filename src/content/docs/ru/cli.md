У установленной копии есть небольшая командная строка. Она говорит с работающим сервисом, а не запускает второй.

## Точки входа

| Вход | Использование |
|---|---|
| `run.cmd` | Самый короткий путь; запускает приложение через встроенное виртуальное окружение |
| `.venv\Scripts\python.exe main.py` | Явная точка входа Python |

Старый README упоминает `VibeForma.exe`. Отдельного исполняемого файла в 0.4.0 нет: установленная копия — это копия исходников с `run.cmd`, `main.py` и `.venv`. Используйте один из двух входов выше.

Примеры ниже используют `run.cmd`.

## Флаги

| Флаг | Что делает |
|---|---|
| `--toggle` | Начинает или останавливает запись. |
| `--cancel` | Отбрасывает запись или черновик панели. |
| `--status` | Печатает `status.json` работающего экземпляра: state, version, pid, ts. |
| `--transcribe <file>` | Транскрибирует один аудио- или видеофайл через именованный канал. |
| `--transcribe-folder <dir>` | Ставит в очередь каждый поддерживаемый файл папки одним пакетом. |
| `--cancel-batch [<id>]` | Останавливает все незавершённые пакеты или названный. |
| `--doctor` | Выполняет диагностические проверки и печатает `OK` / `WARN` / `FAIL` по строке. |
| `--selftest` | Выполняет импорты, загружает модель, распознаёт `test_ru.wav` и печатает текст. |
| `--help` | Печатает весь контракт команд, включая файловые и папочные опции. |

### `--toggle`

```powershell
.\run.cmd --toggle
```

То же, что нажатие горячей клавиши диктовки: начало или остановка записи.

### `--cancel`

```powershell
.\run.cmd --cancel
```

Отбрасывает фразу или черновик панели. Ничего не вставляется.

### `--status`

```powershell
.\run.cmd --status
```

Печатает состояние работающего экземпляра:

| Поле | Значение |
|---|---|
| `state` | idle, recording, processing, paused, updating, error |
| `version` | Версия продукта |
| `pid` | Идентификатор процесса |
| `ts` | Метка времени |

Ответ старше 60 секунд не считается текущим. `status.json` — удобство, а не источник истины.

### `--transcribe`

```powershell
.\run.cmd --transcribe "D:\audio\meeting.mp4"
.\run.cmd --transcribe "D:\audio\note.m4a" --format txt --out "D:\text" --json
```

Транскрибирует один аудио- или видеофайл. Вызов идёт к запущенному сервису через именованный канал текущего пользователя и никогда не открывает порт. Прогресс печатается в stderr; stdout несёт путь результата или JSON-объект при `--json`.

| Опция | Значение |
|---|---|
| `--lang <code>` | Язык распознавания, например `ru` или `en`; по умолчанию из конфигурации |
| `--format <name>` | `txt`, `json`, `srt`, `vtt` или `all`; по умолчанию `srt` |
| `--out <path>` | Записать результат туда, а не рядом с исходником |
| `--json` | Машиночитаемый ответ в stdout |
| `--force` | Перезаписать существующий выходной файл |

### `--transcribe-folder`

```powershell
.\run.cmd --transcribe-folder "D:\audio\podcast" --recursive --format srt --json
```

Ставит в очередь каждый поддерживаемый файл папки. По умолчанию берётся верхний уровень; `--recursive` включает подпапки. `--out` зеркалит дерево папки под указанным местом, существующие результаты пропускаются без `--force`, а один плохой файл не останавливает пакет. Команда печатает JSON-сводку.

### `--cancel-batch`

```powershell
.\run.cmd --cancel-batch
.\run.cmd --cancel-batch 3f2a1c
```

Останавливает все незавершённые пакеты или пакет с названным id. Текущий файл останавливается на границе сегмента, очередь не продолжается.

### `--doctor`

```powershell
.\run.cmd --doctor
```

Проверяет Python, зависимости, модель на диске, профиль CUDA/CPU, микрофон, горячую клавишу, настройки обновления, свободное место и переключатели приватности. Каждая строка — `OK`, `WARN` или `FAIL`; код возврата 0, если провалов нет, и 1 иначе.

Отчёт только читает. В нём нет продиктованного текста, заголовков окон, hotwords, словаря, истории и HTTP-токена. В окне настроек есть кнопка **Скопировать отчёт** для того же вывода.

### `--selftest`

```powershell
.\run.cmd --selftest
```

Выполняет фиксированную цепочку: импорты → модель → `test_ru.wav` → распознанный текст. Код 0 — цепочка прошла, 1 — нет. WAV есть и в свежем git-клоне, и в установленной копии.

Это самый быстрый способ доказать, что распознавание на машине работает, независимо от микрофона.

## Коды возврата

| Код | Значение |
|---|---|
| 0 | Успех — команда выполнена или проверки прошли. |
| 1 | Нет работающего экземпляра, ошибка сервиса или задачи, провал проверки, провал selftest или неверная команда. |
| 2 | Плохие аргументы — неизвестная опция, отсутствующее значение, неизвестный формат или второй входной файл. |
| 3 | Транскрибация или пакет отменены. |
| 4 | `--transcribe-folder` не нашёл, что транскрибировать. |

`--toggle`, `--cancel`, `--status`, `--transcribe` и `--transcribe-folder` требуют работающего сервиса. Без него они возвращают 1. Пока модель загружается, файловый вызов отвечает `the model is loading` и выходит с кодом 1; повторите позже.

## Команда хука

`hook_command` отправляет распознанный текст вашей команде:

- текст приходит на **stdin** в UTF-8;
- команда запускается **без shell**, поэтому метасимволы — обычные символы;
- таймаут 1–30 секунд (`hook_timeout_s`);
- сбой или таймаут пишется в лог только как статус;
- вставка не затрагивается; хук работает параллельно.

Пример: небольшой Python-скрипт, который дописывает текст в заметку дня.

```powershell
.\run.cmd --status
```

Затем задайте `hook_command` в `config.json`, например:

```json
"hook_command": "python C:\\tools\\vibe-hook.py",
"hook_timeout_s": 5
```

Поскольку shell нет, не полагайтесь на `|`, `>`, `&&` или раскрытие переменных внутри строки команды. Логику кладите в скрипт.

## Рецепты для скриптов

Начать диктовку со Stream Deck или из скрипта:

```powershell
.\run.cmd --toggle
```

Проверить, свободен ли сервис, перед отправкой работы:

```powershell
.\run.cmd --status
```

Проверить свежую установку без микрофона:

```powershell
.\run.cmd --selftest
```

Собрать отчёт для поддержки:

```powershell
.\run.cmd --doctor > doctor.txt
```

Транскрибировать запись и получить машиночитаемый ответ:

```powershell
.\run.cmd --transcribe "D:\audio\call.m4a" --format json --json
```

Поставить папку в очередь и прочитать сводку:

```powershell
.\run.cmd --transcribe-folder "D:\audio\inbox" --recursive --json
```
