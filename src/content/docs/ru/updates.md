VibeForma проверяет GitHub Releases в фоне и предлагает новую версию. Молча она ничего не ставит, если вы явно об этом не попросили.

## Когда происходят проверки

| Момент | Деталь |
|---|---|
| После старта | Примерно через 90 секунд после запуска сервиса |
| Повторно | Каждые `update_interval_h`, по умолчанию 2 часа |
| Условие | Только когда сервис в простое |
| Вручную | **Проверить обновления** в шапке окна настроек |

С 0.4.3 текущая версия и кнопка **Проверить обновления** находятся в шапке окна настроек на каждой странице. Дублирующая кнопка проверки внизу страницы «Система» убрана; переключатели обновлений остаются там.

Проверки можно выключить в настройках. С выключенными проверками приложение само к GitHub не обращается.

## Что происходит при найденном релизе

Новый релиз **предлагается**, а не ставится:

- на панели появляется синяя кнопка **Обновить**;
- трей показывает релиз;
- уведомление содержит выжимку release notes;
- **Позже** закрывает предложение.

Обновление ставится только когда вы его принимаете, либо безусловно, только если `auto_update` равен `auto` — это явный выбор, а не значение по умолчанию.

Если в этот момент идёт запись или файловое задание (один файл либо пакет), обновление откладывается и ждёт их завершения; в режиме `auto` оно повторяется само после окончания работы.

В трее также есть пункт **Что нового в …**, который открывает страницу релиза.

## Как ставится обновление

1. VibeForma скачивает релизный архив и файл `SHA256SUMS` с GitHub.
2. Сверяет архив с `SHA256SUMS` до распаковки: при отсутствии файла, строки с архивом или несовпадении хеша установка останавливается.
3. Сохраняет бэкап текущей установки.
4. Ставит новую версию тем же установщиком, что и при первой установке.
5. Перезапускает сервис отдельным процессом `pythonw`.

Модель, словарь, история и `config.json` сохраняются.

Пока состояние `updating`, горячая клавиша и запись заблокированы, поэтому обновление не столкнётся с диктовкой.

## Подписи

Сертификата подписи кода и подписанного манифеста нет. Релиз — обычный zip на GitHub с файлом `SHA256SUMS`. VibeForma проверяет контрольную сумму: это ловит повреждённую загрузку, но не доказывает, кто собрал архив.

Windows SmartScreen может предупредить при запуске установщика или приложения. Для неподписанной сборки это ожидаемо.

## Откат

Если обновление не удалось, прежняя установка восстанавливается из бэкапа. Если сервис не поднялся, бэкап — путь восстановления; `install.log` называет сбойный шаг.

## Ручное обновление

Скачайте последний релиз и запустите установщик снова. Установщик обнаружит существующую установку, сохранит данные и продолжит с того шага, который требует работы.

```powershell
irm https://raw.githubusercontent.com/FormaMindPro/vibeforma/main/install.ps1 -OutFile install.ps1
.\install.ps1
```

## Если обновление не завершилось

1. Проверьте `install.log` в каталоге установки.
2. Проверьте свободное место: новой версии нужно место под архив и бэкап.
3. Проверьте сеть и состояние GitHub.
4. Перезапустите приложение. Повторная установка продолжит с места сбоя.
5. Если сервис не стартует, восстановите установку из бэкапа, созданного обновлятором.
6. Если папка осталась смешанной — часть файлов старой версии, часть новой — сделайте полный сброс: закройте приложение, удалите каталог установки и поставьте заново в то же место. Отсутствующую папку установщик считает чистой установкой. Шаги — на странице [Установка](/ru/installation/).
