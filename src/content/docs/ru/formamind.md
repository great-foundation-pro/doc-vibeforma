VibeForma и FormaMind — две части одной системы.

- **FormaMind** — проектный инструмент: в нём живут проекты, задачи и работа вокруг них.
- **VibeForma** — голосовой слой: он превращает речь в текст для кода, документов, видео и подкастов.

Идея проста: вместо переключения между проектным инструментом и отдельным приложением диктовки вы говорите прямо в ту работу, которой уже заняты.

## Зачем голосовой слой

FormaMind используется на полную мощность, когда текст приходит со скоростью мысли:

- **Вайп-кодинг** — диктовка инструкций, комментариев, сообщений коммитов и документации в редактор или ИИ-ассистента.
- **Тексты** — черновики, спецификации, ответы и заметки, произнесённые вместо напечатанных.
- **Видео и подкасты** — превращение записей в текст, который можно искать, цитировать и переиспользовать.

VibeForma существует, чтобы этот слой был локальным, предсказуемым и всегда доступным: одна горячая клавиша, без аккаунта, без выгрузки.

## Что работает сегодня

| Возможность | Статус |
|---|---|
| Диктовка в любое приложение Windows, включая редактор или окно FormaMind | Работает в 0.2.4 |
| Локальное распознавание на faster-whisper | Работает |
| Словарь и сниппеты для лексики проекта | Работает |
| Командная строка: `--toggle`, `--cancel`, `--status`, `--doctor`, `--selftest` | Работает |
| Локальный HTTP API на `127.0.0.1` | Работает при включении |
| `hook_command` — отправка распознанного текста своей команде | Работает при настройке |
| Транскрибация файлов видео и подкастов | Не в 0.2.4; план 0.3.0 |
| Нативная интеграция с FormaMind | В разработке |

Честный итог: VibeForma уже работает как инструмент диктовки. FormaMind находится в разработке, и нативный мост между ними не завершён.

## Как использовать VibeForma с проектным инструментом сегодня

### Диктовать в редактор

1. Откройте окно FormaMind, редактор или ИИ-ассистента.
2. Поставьте курсор в поле ввода.
3. Нажмите `Ctrl+Alt+Space` и говорите.
4. Текст вставляется в окно, активное в момент нажатия клавиши.

Добавьте имена проектов и термины в [словарь](/ru/dictionary/), чтобы они распознавались и писались единообразно.

### Отправлять текст команде

`hook_command` получает распознанный текст на stdin в UTF-8, запускается без shell и имеет таймаут 1–30 секунд. Сбой пишется в лог как статус и не влияет на вставку. Это простейший способ передать текст локальному скрипту, файлу заметок или обвязке агента.

### Вызывать локальный API

Когда API включён, локальный инструмент может:

- проверить `GET /health` — состояние, версия, модель и язык;
- отправить WAV в `POST /transcribe` с заголовком `X-VibeForma-Token`.

API работает только на loopback, ограничен по частоте и принимает WAV до 10 МБ. Подробнее — [Локальный API](/ru/local-api/).

### Управлять сервисом из командной строки

`--toggle`, `--cancel` и `--status` говорят с работающим экземпляром. Скрипт может начать диктовку, отменить её или прочитать состояние, не касаясь интерфейса. Подробнее — [Командная строка](/ru/cli/).

## Что создаётся

- **Транскрибация файлов (0.3.0)** — второй вход в тот же движок: файл вместо микрофона. Заявленные выходы — TXT, JSON, SRT и VTT, с таймкодами, очередью заданий, паузой и возобновлением, приоритетом живой диктовки. Именно это превращает записи видео и подкастов в текст внутри одного рабочего процесса.
- **Поверхности для агентов и обвязок** — именованный канал, расширенный `location.json`, путь CLI `--transcribe` и OpenAI-совместимый эндпоинт транскрибации.
- **Нативная интеграция с FormaMind** — голосовое управление задачами проекта и более тесная связь проектного инструмента с голосовым слоем.

Это планы, а не выпущенные функции. [Дорожная карта](/ru/roadmap/) называет их без дат, а опубликованная документация не обещает их как доступные.

## Что это значит для вас сегодня

- Если нужна **локальная диктовка на Windows**, VibeForma готова сейчас. Начните с [Быстрого старта](/ru/quickstart/).
- Если нужна **транскрибация видео и подкастов**, её нет в 0.2.4. Следите за [дорожной картой](/ru/roadmap/) или пока используйте инструмент транскрибации файлов.
- Если вы **строите интеграцию**, CLI, хук и локальный API доступны уже сегодня; файловые и агентские поверхности проектируются для 0.3.0.
