VibeForma — открытый проект по лицензии MIT. Вклад приветствуется: issues, исправления, локали и документация.

## Перед началом

- Поищите в существующих issues и pull requests.
- Для крупного изменения сначала откройте issue, чтобы согласовать объём.
- Для проблемы безопасности следуйте [Безопасности](/ru/security/), а не открывайте публичный issue.

## Сообщение об ошибке

Укажите:

1. Версию VibeForma (шапка окна настроек или `run.cmd --status`).
2. Версию Windows и наличие видеокарты NVIDIA.
3. Шаги воспроизведения.
4. Ожидаемый и фактический результат.
5. Отчёт `--doctor`.
6. Нужную часть лога.

Вырежьте токен API и личный текст. Отчёт доктора и так исключает и то, и другое.

## Вклад в код

| Правило | Деталь |
|---|---|
| Язык | Английский в коде, комментариях, логах и коммитах. |
| Кодировка | Исполняемый код — ASCII. |
| Тесты | Добавьте или обновите тесты на изменение поведения. |
| Линтер | `python tools/ruff_gate.py` не должен добавлять находок. |
| Типизация | Strict `mypy` для `app/vibeforma`. |
| Объём | Одно изменение на pull request; несвязанные рефакторинги отдельно. |

Перед отправкой выполните:

```powershell
.venv\Scripts\python -m pytest -q
.venv\Scripts\python tools\ruff_gate.py
.venv\Scripts\python -m mypy app\vibeforma
```

## Правила языка

- Ядро английское.
- Кириллица разрешена только в `app/locales/*.json`, русских текстах установщика, ru/uk промптах ASR и `README.ru.md`.
- Правило проверяется тестом; pull request с нарушением падает в CI.

## Добавление языка интерфейса

1. Скопируйте `app/locales/en.json` в `app/locales/<код>.json`.
2. Переведите значения, не меняя ключи.
3. Запустите тесты локалей; парность ключей проверяется.
4. Язык появляется в настройках автоматически.
5. Отсутствующие ключи откатываются на английский.

## Изменения документации

- Каждая страница существует на английском в корне и на русском под `/ru/` с тем же slug.
- Обе версии меняются в одном pull request.
- Стандарт страницы: один H1, sentence case, второе лицо, активный залог, без маркетинга.
- Подписи интерфейса в тексте совпадают с локалью страницы.
- Скриншоты, если добавлены, — на языке страницы и с alt-текстом.
- Сборка и проверка:

```powershell
cd project\production\vibeforma.pro
npm run verify:all
```

## Сообщения коммитов

Пишите по-английски, в повелительном наклонении, с короткой темой. Тело объясняет почему, а не что — что видно в diff.
