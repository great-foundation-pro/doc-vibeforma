Эта страница суммирует пользовательские изменения. Авторитетный журнал — [`CHANGELOG.md`](https://github.com/FormaMindPro/vibeforma/blob/main/CHANGELOG.md) в репозитории и страница GitHub Releases.

Документация описывает **0.2.4**.

## 0.2.4 — 22 ноября 2026

### Добавлено

- Токен локального API создаётся и сохраняется автоматически при первом включении API, в том числе если `config.json` написан вручную с уже включённым переключателем.
- Если настроенный порт API (8787) занят, сервис занимает свободный loopback-порт и публикует фактический порт в `location.json`.

### Исправлено

- Захват звука следует формату устройства — WASAPI на частоте устройства (mono, затем stereo), legacy host API на своей частоте, 16 кГц как последний вариант — с windowed-sinc ресемплингом и одним повтором.

## 0.2.3 — 20 ноября 2026

### Изменено

- Релизы — обычные zip-архивы. Упакованный Windows-исполняемый файл и его сборка убраны; установленная копия — копия исходников с `run.cmd`, `main.py` и `.venv`.
- Релизные архивы выходят с `SHA256SUMS`; подписанного манифеста нет.

## 0.2.2

### Добавлено

- `Ctrl+S` сохраняет настройки, не закрывая окно, с подтверждением на месте.
- Скруглённые углы и тёмная полоса заголовка окна настроек через DWM; безрамочная панель обрезается до скруглённого региона, который перестраивается после каждого ресайза.

### Изменено

- У окна настроек стабильная геометрия: размер считается один раз от самой высокой вкладки, ограничивается экраном и центрируется.

## 0.2.0 — 20 ноября 2026

### Добавлено

- Окно настроек с сайдбаром и разделами.
- `--selftest`: импорты, модель, `test_ru.wav` и распознанный текст, код возврата 0 или 1.
- `uninstall.cmd` / `uninstall.py` с `--remove-data` и `--keep-data`.
- Защищённая смена горячей клавиши: невалидное сочетание не сохраняется; при сбое слушателя прежнее сочетание остаётся.

### Изменено

- Настройки записи, панели, звуков, горячей клавиши, устройства ввода, автозапуска и метода вставки применяются к работающему сервису без перезапуска.

## Ранее, 0.1.x

Проверенные штрихи линии 0.1:

- меню трея и значок, окрашиваемый по состоянию;
- проверка обновлений с выжимкой релиза и пунктом «Что нового»;
- DPI-aware геометрия панели и настроек;
- перезапуск сервиса после обновления;
- кнопка обновления на панели;
- ротация логов.

## Как читать номера версий

VibeForma использует `major.minor.patch`:

- **patch** — исправления и небольшие изменения поведения;
- **minor** — новые функции, включая транскрибацию файлов, заявленную для 0.3.0;
- **major** — ломающее изменение, пока не планируется.

Release notes называют пользовательские изменения; внутренние рефакторинги могут быть только в истории коммитов.
