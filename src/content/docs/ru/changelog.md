## 0.4.0 — 22 ноября 2026

### Добавлено

- **Пакеты папок.** **Трей → «Транскрибировать папку…»** или `--transcribe-folder <dir>` ставит в очередь каждый поддерживаемый файл папки: верхний уровень по умолчанию, `--recursive` — с подпапками. Результаты ложатся рядом с исходниками или зеркалят дерево под `--out`; существующий результат пропускается без `--force`; один плохой файл записывается, остальные продолжаются; отмена останавливает текущий файл и очередь. CLI печатает JSON-сводку и выходит с кодом `4`, если в папке нечего расшифровывать.
- **Живая полоса прогресса** в панели для одного файла и пакета: движущаяся полоса, имя текущего файла, его процент, счётчик пакета `N/M — P%`, различимые состояния «в очереди / транскрибация / пауза / готово / ошибка» и ошибка одного файла, пока пакет продолжается. Готовый результат скрывается через 8 секунд.
- **Пакетный вывод длинных файлов.** Файлы от 60 секунд проходят через `faster_whisper.BatchedInferencePipeline` на той же загруженной модели, блоками по 600 секунд, с тем же языком, VAD, промптом и настройками против галлюцинаций. Это управляется ключами `file_batched` (по умолчанию `true`) и `file_batch_size` (по умолчанию `8`, в пределах 1–16). На тестовой машине проекта MP4 длиной 660 секунд прошёл в 5,2 раза быстрее последовательного пути; при сбое пакетного пути задача откатывается без дублей.
- **Защита при смене целевого окна.** Диктовка по горячей клавише, завершившаяся в другом окне, оставляет текст в черновике панели с действиями вставки, правки, копирования, словаря и отмены при включённом `confirm_focus_change`, а при выключенном — отправляет его в буфер обмена.

## Как читать номера версий

VibeForma использует `major.minor.patch`:

- **patch** — исправления и небольшие изменения поведения;
- **minor** — новые функции;
- **major** — ломающее изменение, пока не планируется.

Release notes называют пользовательские изменения; внутренние рефакторинги могут быть только в истории коммитов.
