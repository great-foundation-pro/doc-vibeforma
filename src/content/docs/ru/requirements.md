Это проверки, которые выполняет установщик, и факты, на которые опирается приложение. Числа взяты из исходного кода и установщика 0.2.4, а не из оценок.

## Операционная система

| Требование | Значение |
|---|---|
| Версия Windows | Windows 10 сборки 1809 или новее, либо Windows 11 |
| Архитектура | x64 или ARM64 |
| Права администратора | Не требуются |
| Каталог установки | По умолчанию `%LOCALAPPDATA%\VibeForma` |

VibeForma — приложение для Windows. Версий для macOS, Linux, iOS и Android нет.

## Python

| Требование | Значение |
|---|---|
| Python для установщика | 3.10, 3.11, 3.12, 3.13 или 3.14 |
| Python для установки из исходников | Тот же диапазон |
| Встроенный Python | Нет — установщик использует Python, найденный на машине |

Установщик останавливается с явной причиной, если Python отсутствует или выходит за поддерживаемый диапазон.

## Место на диске

Установщику нужно свободное место под выбранную модель плюс около 4 ГБ для приложения, зависимостей и рабочих файлов.

| Модель | Примерный размер |
|---|---|
| `large-v3` | 3,1 ГБ |
| `large-v3-turbo` (по умолчанию) | 1,6 ГБ |
| `medium` | 1,5 ГБ |
| `small` | 0,5 ГБ |

Модели лежат в `models\<имя>` внутри папки сервиса. Если модель уже есть в общем кэше Hugging Face, VibeForma может взять её оттуда вместо повторной загрузки.

## Процессор и графика

| Профиль | Когда используется | Точность |
|---|---|---|
| NVIDIA CUDA | Найдена видеокарта NVIDIA и рабочая установка CUDA | float16 |
| CPU | Нет рабочей CUDA или передан `-Cpu` | int8 |

Колёса CUDA (`nvidia-cublas-cu12`, `nvidia-cudnn-cu12`) ставятся только при выборе профиля CUDA. Конфигурация, где указано `cuda` на машине без CUDA, исправляется автоматически.

Установщик не проверяет объём RAM. Крупные модели требуют больше памяти и работают медленнее на CPU; замер README для фразы 12,5 секунды с CUDA float16, лучшее из трёх — 1,53 с для `large-v3` и 0,64 с для `large-v3-turbo`.

## Сеть

| Назначение | Когда |
|---|---|
| Загрузка модели | Один раз, при установке или первой смене модели |
| Проверка обновлений | Примерно через 90 секунд после старта, далее каждые 2 часа по умолчанию, только в простое |
| Загрузка обновления | Когда вы принимаете обновление |
| Распознавание | Никогда — оно идёт локально |

После того как модель лежит на диске, диктовка работает офлайн.

## Звук

- Любое устройство ввода, которое видит Windows.
- Захват сначала пробует формат самого устройства (WASAPI, mono, затем stereo), потом legacy host API, потом 16 кГц.
- Преобразование частоты идёт windowed-sinc ресемплером.
- Если чистый путь не сработал, он повторяется один раз, а причина пишется в лог.

## Порты

| Порт | Назначение |
|---|---|
| 8787 | Порт локального API по умолчанию, только `127.0.0.1` |
| Любой свободный loopback-порт | Занимается автоматически, если 8787 занят; фактический порт публикуется в `location.json` |
| Нет | Когда локальный API выключен (по умолчанию) |

Входящий интернет-порт не открывается. API недоступен с другой машины.
