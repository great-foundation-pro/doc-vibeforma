Эта страница перечисляет настройки, которые исходный код и документация 0.4.0 называют явно. Настройка интерфейса без документированного ключа всё равно живёт в `config.json`, но выдуманного имени ключа здесь нет.

Значения по умолчанию — то, что записывает свежая установка.

## Запись

| Настройка | Ключ | По умолчанию | Значения | Эффект |
|---|---|---|---|---|
| Устройство ввода | хранится в `config.json` | системное по умолчанию | устройство ввода Windows | Микрофон, который захватывает VibeForma. |
| Удержание | `hold_to_talk` | `false` | `true` / `false` | `true` — держать клавишу, пока говорите; `false` — нажал-старт, нажал-стоп. |
| Тишина до конца фразы | `silence_ms` | `2000` | миллисекунды | Сколько тишины завершает фразу. |
| Максимальная длина фразы | `max_record_s` | `120` | секунды | Жёсткий стоп для длинной фразы. |
| Интервал частичных транскрипций | `partial_every_s` | `1.5` | секунды | Как часто частичный текст уходит в панель. |
| Сигнал начала | `beep_on` | — | `true` / `false` | Звук при старте записи. |
| Сигнал конца | `beep_off` | — | `true` / `false` | Звук при остановке записи. |
| Метод вставки | `paste_method` | `Shift+Insert` | `Shift+Insert`, `Ctrl+V` | Как вставляется текст. |
| Возврат буфера | `restore_clipboard` | вкл. | `true` / `false` | Вернуть прежний буфер примерно через секунду после вставки. |
| Исключить из истории буфера | `clipboard_exclude_history` | вкл. | `true` / `false` | Пометить продиктованный текст исключённым из истории и облачного буфера Windows. |
| Уведомлять с текстом | `notify_text` | `false` | `true` / `false` | Показывать продиктованную фразу в уведомлении, а не только число знаков. |

## Статистика

У статистики нет настроек. Она считает диктовки, слова, знаки и секунды по дням и хранит числа в `stats.json`.

## Транскрибация файлов

Эти ключи живут в `config.json`; отдельной вкладки в окне настроек у них нет.

| Настройка | Ключ | По умолчанию | Значения | Эффект |
|---|---|---|---|---|
| Разрешённые корни | `file_roots` | пусто | список папок | Пусто разрешает любой локальный фиксированный или съёмный диск; список ограничивает файловые задачи этими корнями. |
| Максимальный размер файла | `file_max_mb` | `4096` | мегабайты | Более крупный файл отклоняется. |
| Максимальная длительность | `file_max_s` | `21600` | секунды | Более длинный файл отклоняется. |
| Синхронный предел API | `file_max_sync_s` | `900` | секунды | Длинные файлы должны идти в `/jobs`, а не в `/v1/audio/transcriptions`. |
| Хранение задач | `job_keep_s` | `86400` | секунды | Сколько готовая задача живёт в памяти. |
| Пословные таймкоды | `file_word_timestamps` | `false` | `true` / `false` | Добавляет пословные таймкоды в JSON. |
| Включать подпапки | `file_folder_recursive` | `false` | `true` / `false` | Диалог папки в трее обходит подпапки. |
| Пакетный путь длинных файлов | `file_batched` | `true` | `true` / `false` | Файлы от 60 секунд идут пакетным путём вывода. |
| Размер пакета | `file_batch_size` | `8` | 1–16 | Блоков за один пакетный проход. |

## Где живут настройки

`config.json` в каталоге установки, рядом с точкой входа (`run.cmd`, `main.py`) и папкой `.venv`. См. [Файлы и расположение](/ru/files-and-paths/).

Настройки сохраняются по `Ctrl+S` в окне настроек. Большинство применяется к работающему сервису сразу; смена модели идёт через диалог прогресса.
